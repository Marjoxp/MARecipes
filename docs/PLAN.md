# Plan de trabajo y entrega

Fuente: Tarea-3.pdf proporcionado por la estudiante. El documento exige una aplicación con API; no obliga a integrar un modelo de IA.

## Orden de trabajo

1. **Evidencia de GitHub Student Developer Pack.** Estado comunicado por la autora: primera solicitud denegada; segunda solicitud enviada y en revisión. Pendiente: adjuntar captura de la nueva solicitud; la denegación puede conservarse como antecedente. Avisar al docente de que está en revisión. Perfil: https://github.com/Marjoxp. No declarar GitHub Pro activo hasta confirmarlo.
2. **Planificar y declarar IA.** Elegir API, definir funciones y escribir README y bitácora. Mantener commits por etapas bajo la identidad Git configurada de Marjoxp, declarando la asistencia de IA.
3. **Construir interfaz.** HTML semántico, CSS adaptable a móvil, buscador, categorías y detalle de receta.
4. **Consumir API.** Peticiones reales con fetch; mostrar ingredientes y preparación. Manejar carga, ausencia de resultados, desconexión, tiempo de espera y HTTP 429. Incluir reintento.
5. **Verificar.** Probar contrato de API y errores con respuestas simuladas; probar conexión real y uso en navegador cuando el entorno lo permita. Registrar resultados reales y sus límites.
6. **Completar bitácora.** Documento breve de 1 a 2 páginas con al menos cinco prompts auténticos copiados literalmente, resultados, correcciones, un error de IA detectado por la estudiante y reflexión personal. Nunca convertir sugerencias de prompts en conversaciones realizadas.
7. **Preparar demostración.** Hasta tres minutos: búsqueda, detalle, error, fetch y manejo de errores. Entregar enlaces, README, bitácora y evidencia de Student Pack.
